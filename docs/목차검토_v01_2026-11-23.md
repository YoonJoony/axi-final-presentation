## 3. 결합층 애니메이션 (18장) — 순서

**처음 보이는 그림(불 모두 꺼짐):**
```
[업로드] → [1차 확정 검사: 해시 · 백신 · YARA] → [신호판 3줄] ──→ [결합층: 무게 합 · 형식별 기준선] → [정밀 검사]
                     │                       PE     : [위험 점수 게이지] [A] [B] [F]                    └→ [통과 후보]
                     └→ [차단]               Office : [M] [O]  · 기록만 [E] [X] [S]
                                             PDF    : [M] [O] [S] · 기록만 [X] [E]
```
- 신호마다 고유 색(예: M 주황 · O 보라 · S 청록 · 위험 점수 파랑 · A·B·F 각각 다른 색). '기록만' 신호는 흐리게(무게가 0이라 정밀 검사를 결정하지 않음).
- 줄마다 결합층으로 가는 선이 하나씩 있고, 불이 켜지면 그 선이 신호 색으로 빛나며 빛이 결합층까지 이동한다.

| → 누를 때 | 무엇이 보이나 (전부 빠르게: 한 동작 0.3~0.45초, 한 단계 약 1.5초 안) |
